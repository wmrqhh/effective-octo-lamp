# 霓虹斗士

一个纯前端、无需联网的二维单机格斗游戏原型。玩家在浏览器中操控蓝色斗士，对战粉色 AI 影刃。

## 运行方式

直接打开 `index.html`，或在项目目录启动任意静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作

### 安卓 / 触屏

- 点 `开始`：开始 / 重新开始
- 按住 `←` / `→`：左右移动
- 点 `跳`：跳跃
- 按住 `防`：防御
- 点 `拳`：轻拳
- 点 `踢`：重踢

### 键盘

- `A` / `D`：左右移动
- `W`：跳跃
- `S`：防御
- `J`：轻拳
- `K`：重踢
- `Enter`：开始 / 重新开始

## 玩法特性

- Canvas 绘制的 16:9 霓虹街机场景
- 玩家与 AI 的血量、能量、胜场和倒计时 HUD
- 轻拳、重踢、防御、击退、受击硬直和屏幕震动反馈
- 会追击、后撤、防御和出招的本地 AI 对手
- 安卓浏览器可用屏幕虚拟按钮直接开始和操作
